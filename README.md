# Análise de Disciplinas de Ginástica

Projeto desenvolvido em **Python** para organização e análise de dados relacionados às disciplinas de Ginástica em cursos de Educação Física.

## Sobre o projeto

O programa reúne informações de diferentes instituições de ensino e realiza cálculos relacionados à carga horária das disciplinas e à participação de atividades de extensão.

A análise permite visualizar:

* Carga horária total das disciplinas;
* Carga horária destinada à extensão;
* Percentual de extensão por disciplina;
* Média de extensão das disciplinas;
* Quantidade de disciplinas sem carga horária de extensão;
* Disciplina com maior percentual de extensão;
* Média de extensão por instituição de ensino;
* Ranking das instituições de acordo com a média de extensão.

## Tecnologias utilizadas

* **Python**
